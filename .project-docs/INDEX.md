## 마일스톤 (M1~M4)

상세는 [1_DESIGN §1.5](1_DESIGN.md#15-마일스톤-분할), 실행 단계 정본은 [tasks.md](specs/astra-reading/tasks.md).

| 단계 | 목표 | 핵심 기능 | AI |
| :--- | :--- | :--- | :--- |
| **M1** | "내가 읽어 녹음하면 아이가 넘겨보며 듣는다" | 책장·전집 · 촬영 · 부모 녹음 · 기기 TTS · 공통 플레이어 | ❌ |
| **M2** | 편의·데이터 안전 | 백업/복원 · OCR(온디바이스) · 다자녀 · Google 인증·메타 동기화(Firebase 도입) | ❌ |
| **M3** | 부모 목소리 AI | 목소리 등록 → 책별 음원 생성 — **AI 처리자 미정(2026-10-05 101 폐지), 착수 시 재설계** | ✅ 로컬만 |
| **M4** | 확장 | 동영상·클립·자막 · 성장 6각형 통계 | ❌ |

> **M3 는 [A-22 §6] GATE 통과 후에만 착수한다.** `ReadingEvent` 기록은 M1 부터 쌓는다 — 통계 화면(M4)을 켜면 과거 데이터가 이미 있다.

## 범위에서 제외한 것

과거 기획(12 Phase)에 있었으나 **의도적으로 뺀 것**이다.

| 제외 항목 | 사유 |
| :--- | :--- |
| **또래 그룹 랭킹·소셜** | `[A-06-7]` — 아동 데이터를 다른 가족에게 노출한다 |
| **영문 번역 + 원어민 TTS** | 텍스트를 클라우드로 보내야 한다 |
| **클라우드 TTS (edge-tts 등)** | 오너 결정(2026-09-12) — 본문 텍스트를 외부로 보내지 않는다 |
| **AI 목소리 fine-tuning** | 참조 방식으로 충분하다. 학습은 1인 운영에 과하다 |
| **Riverpod·freezed** | `[B-02]` `[현행]` 은 provider. 직렬화는 수동(방어적 파싱 통제) |
| **OS 클라우드 백업(iCloud·Google 드라이브)** | 2026-10-06 오너 결정 — 아동 사진·녹음이 의식 없이 외부로 나가지 않게 한다 |
| **누리과정 추천 큐레이션** | 외부 데이터 의존 + 아동 프로파일링 성격. 보호자가 책에 누리과정 영역을 직접 붙여 모아 보는 것(2026-11-19 [모아보기](specs/watch-topics/requirements.md))은 해당하지 않는다 |
