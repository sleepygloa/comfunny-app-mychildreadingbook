## ⬜ 할 일 (순서)
1. **실기기 E2E (Android)** — 새 책 촬영 → 목소리 넣기 → 재생 → 재시작 위치 복원 → 권한 거부 → 비행기 모드 TTS
2. **백그라운드 재생 실기기** — 잠금화면 · 알림 조작 · 통화/이어폰 분리 정지
3. **가족 기기 백업/복원 수락** — 실제 폰에서 `.mcrb` 저장 → 검사 → 복원
4. 2-3 안정화(파일 누락 · 권한 거부 · 저장 공간 부족 반복 검증, 보류 위젯 테스트 14건)
5. **1~3차 APK 를 폰에 깔아 확인** — 별 누르기 · 주제 정하기 · 모아보기 · 설정 › 최근재생목록 · 제목 눌러 방 고르기 · 📺 영상처럼 보기(캡처가 막히는지)
6. **내 목소리로 책 채우기** — 오너가 만들 곳(집 Mac 추천) · 옮기는 법 · 시작 기준을 정하면 1~2단계(녹음과 글을 짝으로 모으기 · 분량 보기)부터
7. 실제 앱 다음 차례: 누리과정 계획 · 알림 → 음원 넣기 · 재생 ([tasks](specs/watch-topics/tasks.md))
8. 그다음 3단계 편의(다자녀). OCR 은 Android 코드가 있다 — 실기기에서 인식 품질과 릴리스 매니페스트에 `INTERNET` 이 없는지 확인
