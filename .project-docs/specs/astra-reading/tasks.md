## 남은 일

2단계를 닫기 전에 할 일이다. 실기기 항목은 사용자가 재개를 지시할 때 진행한다.

- [ ] **실기기 E2E (Android)** — 최신 APK 업데이트 설치(`install -r`, 데이터 유지) → 새 책 촬영·자르기 → 목소리 넣기 녹음 → 재생 → 앱 재시작 위치 복원 → 권한 거부 → 녹음 중 이탈 → 초안 복원 → 비행기 모드 TTS.
- [ ] **백그라운드 재생 실기기** — 잠금·홈 연속 재생, 알림 pause/play/이전·다음/stop, 통화·이어폰 분리 정지, 편집 중 원격 play 거절, 재시작 시 자동 재생 없음.
- [ ] **가족 기기 백업/복원 수락** — 실제 휴대전화 SAF 저장→검사→복원, 대용량·저장공간 부족, 복사 중 Activity 종료. 수락 전 현재 자료 `.mcrb` 저장 권장.
- [ ] **OS 백업 차단 확인** — Android `dumpsys package` 백업 대상 아님, iOS 빌드 후 iCloud 백업 용량 확인(이 맥은 iOS 빌드 불가).
- [ ] **2-3** 파일 누락·권한 거부·중단·저장 공간 부족 반복 검증, 보류 플레이어 위젯 테스트 14건 원인 해소.
- [ ] **후속 후보** — `.mcrb` 암호화 옵션(키 분실 시 복구 불가 안내 포함) · iOS 백업 파일 UI · 이전 revision·미참조 파일 GC · 다중 프로세스 저장 보장(필요 시) · 연령별 분류 · `GrowthDimensions` 편집 화면(M4).

## 진행 규칙

- 단계마다 결과를 제시하고 검토 지점에서 멈춘다. 다음 단계는 사용자 지시로 착수한다(3단계 OCR/다자녀는 자동 착수하지 않는다).
- 실기기 검증 전에는 MVP 완료로 표시하지 않는다. 설치·앱 시작 성공을 E2E 통과로 해석하지 않는다.
- 테스트·화면 렌더에는 합성 데이터만 쓴다. 사용자 기기에 샘플 데이터를 넣지 않는다.
- 기존 UI·코드 구조 보존 의무는 없다(사용자 결정 2026-09-19). 사용자 데이터 호환성은 지킨다.
