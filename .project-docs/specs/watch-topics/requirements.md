## 화면에서 확인할 것 (시안 기준)

- **주제:** 책장에 주제 줄(큰 주제 → 고르면 아래 주제가 펼쳐짐). 책 줄에 가장 세부 주제 배지. 배지를 누르면 "과학 › 환경 › 대기오염" 과 이 주제 책 보기.
  위 주제를 고르면 아래 주제 책까지 다 나온다.
- **영상처럼 보기:** 책 읽기 📺 · 플레이리스트 📺 로 연다. 검은 배경 · 큰 그림 · 큰 자막 · 자동 넘김 · 전체 진행 막대.
  🔒 한 번 누르면 아이 잠금(조작 버튼 숨김), **1.5초 길게 눌러야** 풀림.
- **움직이는 그림:** ✨ 를 켜면 그림이 천천히 움직인다 — 시안은 확대 · 이동 흉내이고 실제 AI 결과가 아니다.
- **모아보기:** 하단 🧺 탭. 별표 · 주제 · 맞는 나이 · 누리과정 5영역 카드마다 ▶ 전체 재생 · 📺 영상처럼 보기. 카드를 누르면 책 목록.
  책장 책 줄에 ☆/★ 즐겨찾기와 🎂 맞는 나이 배지.
- **책장 맨 위:** 제목 바로 아래 검색창(환영 문구 카드는 뺌). 출판사 · 주제 줄은 평소 숨기고 검색창이나 ⚙ 를 누를 때만 펼친다. 거르는 중이면 작은 칩 하나(예: 🔬 과학 ✕)만 보인다(오너 지시).
- **책 줄:** 표지 크기 고정(56×72) · 모든 줄 같은 높이. 즐겨찾기 별은 표지 오른쪽 아래 모서리에 작게 겹쳐 둔다. 제목 1줄 / 쪽수 · 나이 · 목소리 아이콘(🎙🔊) 1줄 / 주제 배지 1줄(넘치면 흐리게 잘림)(오너 지시).
- **방 고르기:** 맨 위 제목 ▾ → 큰 아이콘 3개(이름은 아이콘 아래). 아이가 보는 화면이라 글자보다 아이콘 위주(오너 지시). 책장 · 플레이리스트 · 모아보기가 그 방의 것만 보이고, 탭 이름(책장 · 노래장 · 영상장)과 ＋ 동작이 바뀐다. 듣던 것은 계속 들린다.
- **누리과정 주간:** 모아보기 맨 위 "이번 주 누리과정" 카드 → 주간 계획(달 · 주 주제, 알림 켜기, 알림 미리 보기).
- **최근재생목록:** 설정 › 듣기 › 열기, 또는 책 읽기 ≡.
- **가족 계정:** 설정에 로그인 자리(계획). 로그인하면 우리 가족 책만, 여러 기기에서 같은 책장.

- 주제 사전 `Topic { id, name, parentId?, emoji, order }` 을 따로 두고 `Content.topicIds: List<String>` 로 참조한다.
  기존 `Content.tags`(자유 글)는 그대로 둔다. 새 필드는 `fromJson` 기본값 `[]` 이라 **schemaVersion 변경 · 마이그레이션 없음**.
  주제는 책 단위(페이지 아님). 처음 20~30개를 넣고 보호자가 추가 · 이름 변경. 지운 주제를 참조하는 책은 배지만 숨긴다.
  새 저장 루트(`index/topics.json`)는 백업 허용 루트 · `RestoreValidator` 에도 넣는다(AGENTS §3).
- 모아보기는 **저장하지 않는 조건 목록**(태그 조건 → 책 목록)이다. 손으로 담는 `Playlist` 와 다르다. 책에 `ageMin` · `ageMax` · `nuriAreas` · `favorite` 를 더한다(기본값 있음, 마이그레이션 없음).
  누리과정 영역은 **보호자가 책마다 고르는 태그**다 — INDEX 의 "누리과정 추천 큐레이션 제외"는 외부 데이터로 아이에게 추천하는 것을 뺀 것이라 이것과 겹치지 않는다. 아이 정보로 거르지 않는다(나이 숫자는 보호자가 고름).
- 방 고르기는 **앱을 셋으로 나누지 않는다.** `Content.type` 에 이미 `pagedBook` · `video` 가 있고 `audio` 하나를 더한다. 화면은 지금 고른 `type` 하나로 거르고(책장 · 플레이리스트 · 모아보기 공통), 서버를 붙일 때(M2c)도 조회에 같은 값을 넘긴다.
  **방 바꾸기는 재조회, 방 안 검색 · 출판사 · 주제 · 별은 필터**(2026-11-19 오너 확인): 저장소에 `listByType(type)` 을 두고 방을 바꾸면 VM 이 다시 불러온다(서버 도입 후에도 같은 계약).
  방 안에서는 불러온 목록을 메모리에서 거른다. 기본 방은 도서관.
  달라지는 곳은 ① 만들기(책 촬영 / 노래 녹음 · 파일 / 영상 가져오기) ② 재생 화면(그림 + 쪽 / 큰 표지 + 가사 / 영상) 두 군데다. 고른 방은 기기에 기억한다.
  플레이리스트는 방마다 따로, 최근재생목록은 하나(섞여도 됨)로 둔다. 순서: 도서관 → 음악방(녹음 재사용이라 쉬움) → 영상관(영상 재생기 · 용량 부담).
- 누리과정 계획은 `NuriPlan { month, theme, weeks[{title, topicIds}] }` 로 보호자가 적는다. 예시는 흔한 생활주제 틀이고 외부에서 받아오지 않는다. 주에 주제 배지를 이어 두면 "이번 주" 모아보기가 저절로 찬다.
  알림은 **기기 안 예약 알림**(매주 월 8시 · 매월 마지막 주 "다음 달 세팅") — 인터넷 · 서버 없이 된다. Android 13+ 알림 권한 요청이 필요하다.
- 영상처럼 보기는 기존 `PlaybackQueue` · `PlayerViewModel` 위의 **다른 화면**이다(새 재생 엔진 아님). 가로 고정 · 화면 꺼짐 방지 · 아이 잠금.
  TV 는 캐스트(Chromecast 등) 또는 태블릿 HDMI — 방식은 착수 때 정한다. 차는 태블릿 오프라인 재생이 기본.
- W-3 은 M2c(Google 인증 · 가족 격리 · Firebase)와 같은 일이다. "자기 것만" 은 가족 단위 격리 규칙으로, "복제 불가" 는 내보내기 기능을 두지 않고
  Android `FLAG_SECURE`(화면 녹화 · 캡처 차단)로 막는다. 사진 · 녹음 원본을 서버에 보관할지는 ADR-1 · 8 과 함께 착수 때 다시 정한다.
- W-4 는 ADR-15. AI 처리는 서버(클라우드 함수 등)를 거쳐 보내고 키는 앱에 넣지 않는다. 결과 영상은 페이지에 `AudioTrack` 처럼 붙는 **장면 트랙**으로 저장한다(원본 사진은 그대로).
  엔진 · 비용 · 저작권 확인은 M3 착수 때. 유료 API 는 쓰기 전에 오너에게 묻는다 `[A-01]`.
