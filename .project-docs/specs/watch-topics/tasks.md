## 1차 — 주제 배지 · 즐겨찾기 · 나이 · 모아보기 (2026-11-22)

- ✅ 주제 사전 · 책 꼬리표 저장(`index/topics.json` · `index/book_tags.json`) + 복원 검사
- ✅ 책장: 인사 카드 제거 · 검색 아래 ⚙ 거르기 · 배지 · 표지 56×72 · 표지 위 별
- ✅ 책 메뉴 "주제 · 나이 정하기" 시트
- ✅ 모아보기 탭, 최근재생목록은 설정 안으로
- ✅ 자동 테스트(직렬화 · 모아보기 계산 · 백업 검사 · 화면 1건)
- ⚪ APK 빌드 · 실기기 확인 — 미실행(이 작업 환경에 Android SDK 없음)

## 3차 — 영상처럼 보기 (2026-11-22)

- ✅ 책 읽기 화면 위 📺 버튼 → `/watch`: 가로 · 전체 화면, 그림만 크게(확대 끔), 목소리가 끝나면 저절로 다음 쪽 · 다음 책(기존 재생 흐름)
- ✅ 화면을 톡 치면 멈춤 · 다시 재생, 좌우로 밀면 쪽 넘기기, 아래에 "3 / 12"
- ✅ 아이 잠금: 뒤로 가기 막음, 오른쪽 위 🔒 를 2초 꾹 눌러야 나감(누르는 동안 동그라미가 찬다)
- ✅ 안드로이드: 캡처 · 녹화 막기(FLAG_SECURE) · 화면 켜 두기(FLAG_KEEP_SCREEN_ON) — 새 의존성 없이 MainActivity 채널. 나가면 둘 다 푼다
- ⚪ **Kotlin 컴파일 · 실기기 확인 미실행**(Android SDK 없음). iOS 는 캡처 막기 없음
- ⚪ TV 로 화면 보내기(크롬캐스트 · 미러링)는 하지 않는다 — FLAG_SECURE 가 켜져 있으면 미러링 화면도 검게 나온다. 차 · TV 에서는 태블릿을 직접 보는 것을 전제로 한다
