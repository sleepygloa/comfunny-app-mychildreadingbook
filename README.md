# mychild-reading — 나의 아이의 책읽기

> 집에 있는 **종이책**을 사진으로 찍어 디지털화하고, **부모 목소리로 읽어주는** 가족용 아동 독서 앱("작은 도서관").

| 항목 | 값 |
| :--- | :--- |
| 대상 | 보호자(촬영·녹음) + 아이(재생) |
| 성격 | 가족 단위 개인 앱 — 공개 서비스 아님, 다른 가족과 데이터 공유 없음 |
| 스택 | Flutter 3.47.3 · **provider** · get_it · go_router · 로컬 JSON/미디어 · 기기 TTS (Firebase 미도입) |
| 현재 단계 | 로컬 MVP — 4탭·촬영·녹음·공통 플레이어·백그라운드 재생·백업/복원(Android) 구현, 실기기 검증 남음 |
| 문서 | [.project-docs/INDEX.md](.project-docs/INDEX.md) · 에이전트 [AGENTS.md](AGENTS.md) · 변경 [CHANGELOG.md](CHANGELOG.md) |

## 무엇을 하는 앱인가

부모가 바쁠 때도 **부모 목소리로** 책을 들려준다.

1. 책장 ＋ 로 책을 만들고 **표지와 펼친 면을 촬영**한다(자르기·밝기 보정)
2. 책 메뉴 **목소리 넣기**에서 페이지마다 **직접 읽어 녹음**하거나, 글을 넣어 **기기 TTS** 로 읽힌다
3. 아이가 책장·플레이리스트에서 골라 **그림을 보며 듣는다** — 화면이 꺼져도 이어서 재생하도록 만들었다(실기기 확인 남음)

고도화 단계(M3)에서는 보호자 목소리를 한 번 등록하면 그 목소리로 책을 읽어주는 음원을 **집 안에서** 만든다 —
처리 방식은 착수 시 다시 설계한다(설계 당시 처리자였던 101 워커는 2026-10-05 폐지).

## 설계의 핵심

**① 기기 안에서만** — 책 사진·녹음은 **기기가 유일한 진실**이다. 네트워크 코드가 없고, iCloud·Google 드라이브 자동 백업도 막았다(2026-10-06).
기기 밖으로 나가는 것은 사용자가 직접 저장 위치를 고른 `.mcrb` 백업 파일뿐이다.

**② 멀티 오디오 트랙** — 한 페이지에 녹음·기기TTS(·향후 AI 목소리)를 **동시에 보유**하고 재생 중 전환한다.

**③ 클라우드 AI 를 쓰지 않는다** — 책 본문과 부모 목소리를 외부 AI 서비스로 보내지 않는다.

| 단계 | 목표 | AI |
| :--- | :--- | :--- |
| **M1** | 책 등록 · 촬영 · 부모 녹음 · 기기 TTS · 플레이어 | ❌ |
| **M2** | 백업/복구 · OCR · 다자녀 · 인증/동기화 | ❌ |
| **M3** | 부모 목소리 AI (처리자 미정) | ✅ 로컬만 |
| **M4** | 동영상 · 성장 6각형 통계 | ❌ |

실행 단계 0~6 과 종료 조건: [tasks.md](.project-docs/specs/astra-reading/tasks.md) · 화면 설계: [design.md](.project-docs/specs/astra-reading/design.md).

## 실행

```bash
# 저장소 루트에서
flutter pub get
flutter run          # 실기기 권장 — 카메라·마이크·기기TTS 가 필요하다
```

명령어 없이 쓰려면 USB 휴대폰 한 대를 연결하고 **[build-install-android.command](build-install-android.command)** 를 Finder 에서 더블클릭한다 —
빌드·데이터 유지 업데이트 설치·앱 실행까지 진행한다. 상세: [2_DEVELOPMENT §2.1](.project-docs/2_DEVELOPMENT.md#21-개발-환경).

## 백업 (Android)

설정 → 백업 파일 → **백업 파일 저장**으로 원하는 로컬 위치에 `.mcrb` 를 보관하고, **백업 파일 검사**로 손상을 확인한다.
**백업으로 책장 복원**은 현재 책장 **전체를 교체**한다(합치기 아님) — 보관할 자료가 있으면 먼저 저장한다.

- `.mcrb` 는 **암호화되지 않은** 사진·녹음 묶음이다. 클라우드 동기화 폴더나 메신저에 두면 그 서비스에 그대로 남는다.
- OS 자동 백업을 막았으므로 **앱을 지우면 자료도 사라진다** — 업데이트는 덮어 설치한다.
- **iOS 는 아직 백업 기능이 없다**(버튼 비활성) — 기기를 잃으면 자료도 잃는다.
