# 화면 프로토타입

휴대폰 브라우저로 여는 **클릭형 화면 시안**이다. 기획 · 화면 논의용이며 실제 앱(Flutter)과 따로 있다.

- `index.html` 한 파일. 책 · 글은 모두 **합성 예시**다(가족 자료 없음).
- 화면마다 오른쪽(휴대폰에서는 📒 버튼) **기획 메모**에 그 화면의 상태(됨 · 확인 남음 · 아직)를 적는다.
- 색 · 크기는 [화면 설계](../.project-docs/specs/astra-reading/design.md) §2 · §1-5 토큰을 따른다.
- 앱 화면이 바뀌면 이 시안과 메모도 같이 고친다. 상태의 정본은 [STATUS](../.project-docs/STATUS.md) 다.
